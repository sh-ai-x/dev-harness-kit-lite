# Rules — dev-harness-kit-lite

| File | Purpose |
|------|---------|
| `git-workflow.md` | Branch + worktree + PR protocol (copied verbatim from full kit; non-overridable) |
| `skill-authoring.md` | SKILL.md frontmatter schema (lite: `alpha` optional) |
| `team-collab.md` | 4-hour MVP cadence, parallel roles, hand-off timing |
| `role-pm-coordinator.md` | PM/coordinator role (1 person, mandatory) |
| `role-frontend.md` | React/Next.js role spec (n people) |
| `role-backend.md` | Python API role spec (n people) |
| `role-figma-mcp.md` | Figma MCP role spec (n people, default 1) |

Read `git-workflow.md` first — its 3 iron laws (main sacred, every task = new worktree, branch from origin/main) are the bedrock.

Read `team-collab.md` second — it sets the 4-hour cadence and the role hand-off protocol.

Read your role spec third — it tells you exactly which directories you own and which paths are off-limits.
